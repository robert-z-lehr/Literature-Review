# Literature Review — Urban Heat, Shade Infrastructure, and Pedestrian Thermal Resilience

Public research repository and GitHub Pages site for:

- urban heat mitigation
- pedestrian thermal exposure
- stoplight-mounted shade structures
- transit and sidewalk thermal comfort
- equity-oriented infrastructure planning
- urban climate adaptation

Live site:

https://robert-z-lehr.github.io/Literature-Review/

## Repository Purpose

This repository functions as:

1. A structured literature review database
2. A public-facing research communication site
3. A drafting workspace for proposal and review writing
4. A reference archive for heat, shade, pedestrian, and urban resilience studies
5. A long-term documentation system for PhD research progress
